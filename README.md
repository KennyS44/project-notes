# project-notes

Заметки и задачи по проекту на одной странице: таблицы с текстом, галочками и процентом
выполнения, пометки под каждой таблицей, окна и колонки меняют размер.

Данные хранятся только в браузере (localStorage). Кнопки «экспорт» / «импорт» сохраняют
и загружают всё в файл `.json` — так можно сделать резервную копию или перенести данные
на другое устройство.

Сайт: https://kennys44.github.io/project-notes/
